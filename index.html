How scoring works

    
    
      
  1. Only verified evidence counts. claimed,
        pending and refuted items contribute zero;
        a disputed item blocks scoring until resolved.
    2. 
      
  2. Self-assertion is discounted. Evidence an agent issues about itself
        counts half; third-party and protocol-sealed evidence counts full.
    3. 
      
  3. Sybil damping. At most 2 verified items per identity cluster count
        per family — ten sock-puppet attestations don’t beat one real one.
    4. 
      
  4. Context gates. Each context demands minimum verified evidence
        (e.g. agent-trust needs 3+ verified items across 2+ families,
        including ERC-8004 identity). Miss the gate → insufficient data, with
        the exact shortfall listed.
    5. 
    

    
Published rules, spec-versioned — weights and thresholds change only with a
      spec bump, never ad hoc. Bands: established ≥0.80 · emerging ≥0.60 · thin ≥0.40 ·
      weak ≥0.20 · negligible below.
